# Evidências do Dashboard (Apache Superset)

Conforme a **Seção 11 do Desafio Prático 1**, este diretório armazena as capturas de tela e evidências visuais de comprovação do dashboard em funcionamento no Superset.

## Estrutura recomendada de evidências:
- `01_dashboard_geral.png`: Visão panorâmica do dashboard com os 3 cartões de indicadores, gráfico de barras, gráfico de linhas e filtros interativos.
- `02_filtro_categoria.png`: Demonstração da aplicação do filtro interativo de categoria.
- `03_filtro_nivel.png`: Demonstração da aplicação do filtro interativo por nível de dificuldade.
- `04_kpis_detalhados.png`: Destaque para os cartões de KPIs (Taxa de Conclusão, Cobertura do Catálogo e Total de Interações).

> O arquivo de exportação oficial do dashboard gerado pelo pipeline está salvo em `dashboard/desafio_1.zip`.
